# Projeto de Jogo - JRPG Tagmar com Evolucao Visual

## Visao geral

Este projeto e um jogo com foco principal em `PC`, planejado para futura adaptacao em `mobile`.

A base atual do projeto combina duas direcoes:

- um `JRPG` com inspiracao em `Tagmar`
- uma proposta de `evolucao visual progressiva` ao longo da historia

Com a conversa compartilhada do ChatGPT, a parte mais bem definida neste momento e o `sistema de combate`.

## Pilar principal

O diferencial do projeto passa a ser a uniao entre:

- `progressao narrativa e visual`
- `combate tatico com iniciativa por tempo`
- `adaptacao das sensacoes de Tagmar para linguagem de JRPG digital`

Cada etapa do jogo pode representar nao apenas uma melhoria grafica, mas tambem:

- uma evolucao da tecnologia do mundo do jogo
- uma ampliacao das mecanicas
- um aumento da complexidade dos mapas
- uma progressao emocional e narrativa
- um amadurecimento dos sistemas de combate, magia e status

## Direcao inicial

- Plataforma principal: `PC`
- Plataforma secundaria futura: `Mobile`
- Engine assumida: `Unity` em versao recente, preferencialmente `LTS`
- Genero-base atual: `JRPG`
- Referencia sistemica atual: `Tagmar` adaptado para formato digital
- Modelo de combate-base: `ATB tatico com pausa na decisao`
- Estilo de progressao: fases/eras visuais com transicao gradual

## Proximo passo recomendado

Definir como o conceito de `JRPG Tagmar` se conecta com a ideia de `evolucao visual por eras`.

Hoje a base mais forte do projeto ja nao e mais "qual genero usar", porque isso veio da conversa compartilhada. Agora o ponto mais importante e fechar:

- qual e a historia central
- como a evolucao visual acontece dentro do mundo
- se o combate permanece 2D por menus em todas as eras ou tambem evolui visualmente
